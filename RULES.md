# Rules

## 1. Do not SEO the novel. (FIX #8, Claire, 2026 Oct 3)

Never reshape a Black Cat scene to rank better, answer a question, or summarise for a search engine. No keyword passes on fiction. No retitleing a scene for reach. No quotability tactics - no pull-quote bait, no "share this" hooks inside the scenes. The fiction stays exactly as it is. If a task seems to require touching a Black Cat piece for traffic reasons, stop and ask Claire.

The site can carry discoverability in its code (schema, RSS, sitemap). It cannot carry it in the prose. The descriptions live in `SEO Descriptions — Registry.md` (same folder) - revise them there and in each post frontmatter; never in the scene.

## 2. Mobile first. Desktop is the luxe layer.

Every change lands for the phone first and is judged at phone width. Desktop gets more air, bigger type, more generosity - added on top, never the base.

## 3. Dark teal is the default. Sepia is the mercy, not the default.

## 4. Edits here are not live until synced back to the 2pix/small-things repo and pushed.

The site builds from the repo, not from this folder. See 00-README.md.

## 5. One public identity: the Substack.

No X, no Instagram links unless either opens up. The site says only what's true.
